Deployment Pipeline

Add a frame

Unfiled photos. Each frame gets a permanent number that never changes and is never reused, so /gallery/#f147 keeps working. Date and GPS are read from the file before it is resized — export from Lightroom with Metadata: All and location info left in, or they arrive empty and you fill them in below.

Import an event

Curate the selection in Lightroom, export that collection to its own folder, then point this at the folder. Only what you exported gets imported. Date, location and summary come from the invoice — they are recorded once on the event and every frame inherits them, so photo metadata is not needed.
