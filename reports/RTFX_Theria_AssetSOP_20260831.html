RTFX/THERIA · ASSET SOP · 2026.08.31 · FOR COLLABORATORS

One name, one place,
one current version.

The standing reference for how Theria assets get named, filed, and handed off. Ten minutes to read, and it applies to every deliverable that touches the shared Drive. Questions go to Allen.

01

THE ONE RULE

The PD — the Theria product database — is the single source of truth. Every product, print, design, and colorway gets its canonical name from the PD. If a name isn't in the PD, it doesn't go on a file: ping Allen to add it first, then name the file. Don't invent a name, even a sensible one — two sensible names for the same thing is how we got here.

Renames work the same way: the PD changes first, then filenames follow. Never the other way around.

THE PATTERN — EVERY DELIVERABLE Theria_<Product>_<Design>_<Colorway>_<vNN>_<TYPE>.<ext> Theria_WaterCarafe_Eden_v06_MASTER.ai Theria_Candle_Hands_LtPurple_v01_PRINT.pdf Theria_Jug_Peacock_v02_SOC-9x16.mp4
02

THE FILENAME

Product
PascalCase, from the PD — WaterCarafe, CoffeeCup, TrayLarge, Candle, BakingDishOval
Design
the print or artwork, from the PD — Eden, Hands, Peacock, Leopard, Jellyfish, Vines, Dragon, Lion
Colorway
only when variants exist — LtPurple, DkPurple. No variants, no colorway part.
vNN
always lowercase v + two digits: v01, v06. Never V5, never "final", never "(1)"
TYPE
what the file is for, from the codes below
MASTER
layered working file — .ai, .aep, .prproj, .psd
OL
outlined / flattened print-ready vector
PRINT
print-ready export, with dimensions — PRINT-14x20
TARGET
AR image target
AR
AR video or experience asset, with platform — AR-zappar, AR-snap
WEB · SOC
website / social exports, with ratio where relevant — SOC-9x16
SHOT
photography — product or lifestyle

Animations and videos not tied to one product anchor on the Design instead: Theria_Eden_GardenParty_v02_AR-zappar.mp4.

Never in a shared folder: final, new, copy, (1), raw camera names like 0147.jpg, or app auto-saves. If it isn't named by the pattern, it isn't done.

03

THE TREE

One tree in the shared Theria folder, organized by print first — that's how the brand thinks. The underscore prefix marks a standard folder and sorts it to the top; the _category template keeps working inside each print.

Theria/
  _BRAND/      logos, fonts, brand docs — this SOP lives here
  _PD/         the source-of-truth database + product/packaging specs
  PRINTS/      one folder per PD design — Eden/, Hands/, Teapot/ …
               inside each: _masters · _images · _movs · _outputs · _AR
  PRODUCTS/    per-product print-ready files — what vendors receive
  PHOTO/       shoots by date — 2026-07_ProductShoot/
  MARKETING/   social, website, presentations, catalog
  MUSIC/
  _ARCHIVE/    superseded versions, old shoots — never delete, archive
  _INBOX/      drop zone for anything unsorted — see rule 03

Folders are named for the work, never for people. If you and someone else are trading files, they go in the print or product they belong to — not a folder named after the two of you.

04

THE SEVEN RULES

  1. Name at export, from the PD. Check the PD for the canonical name before saving. Not in the PD? Ping Allen to add it — don't invent one.
  2. One current version, visible. When a new version is approved, the old one moves to _ARCHIVE/ under the same subpath. A folder never shows two versions of the same asset — history within a file is Drive's job; history across exports is v##'s.
  3. The _INBOX rule. Not sure where something goes? Drop it in _INBOX/ with a correct filename — never into a random folder. It gets emptied weekly.
  4. Masters live in Drive; apps work locally. Working files (.aep, .prproj) are edited locally, and the saved master is pushed to the print's _masters at each milestone. Auto-save, cache, preview, and render-scratch folders stay out of Drive sync.
  5. Personal My Drives are drafts only. Anything others need moves to the shared tree the day it's approved. If it's not in the shared Theria folder, it doesn't exist for the team.
  6. Handoffs are folders, not files. Printers, Zappar, retailers get a dated folder in PRODUCTS or the print's _outputs — 2026-08_ZapparHandoff/ — never loose files in chat or email.
  7. Access hygiene. New collaborators get folder-level access, not file links. Shortcuts to external docs get replaced with real shared copies.
05

THE PD TOOL

Finals don't get filed by hand — commissioned pieces go through the PD tool, which names and archives them for you:

  • The dashboard — every commissioned piece and its 0–5/5 delivery status, on one page.
  • The upload page — five slots per piece: image, printable PDF, hi‑res video, low‑res video, QR. Drag a file in and it's named by the pattern automatically and stored in the archive. Re‑uploading a slot creates v02 and retires v01.
  • Share links — any delivered file copies a 7‑day expiring download link for vendors and printers. Send that, not the file.
