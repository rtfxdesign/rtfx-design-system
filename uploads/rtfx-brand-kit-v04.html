02

The wordmark

You already had the hardest asset. Lowercase, heavy, geometric, with an offset inline contour and ruler-graduation hatching on the stems, sitting in a chamfered keyline frame. That is precisely "graphic design meets hardware" — it reads as a machined part and a technical drawing at the same time. Nothing I sketched last round comes close, so the job changes from inventing a mark to building the system around this one.

What it's doing right
✓Inline contour — the offset second outline reads as a drawing of an object, not a letterform. That's the artifex idea encoded in the mark itself.
✓Stem graduations — the hatch marks read as a ruler scale or a knurled grip. Measurement is the single most "hardware" gesture available.
✓Chamfered frame — cut corners on opposing diagonals. Distinctive, asymmetric, and it solves my radius problem better than square corners did.
✓Lowercase — reads as a tool name or a command, not a corporation. Right register for a solo operator.
What it needed — now cut
✓Solid variant. Confirmed: at 32px the inline gaps fill in and turn to mud. Generated a solid cut by stroking the contours at 20 units, which closes the inline without distorting the silhouette.
✓Favicon. The x alone — and the chamfered frame fragment around it reads as a bracket, so it still says RTFX at 32px.
✓One-color solid for vinyl, embroidery and etch — same stroke technique, black and white cuts.
✓Clear space and minimum size defined below and enforced by the geometry, not by eye.
Extracted from your .ai — it's PDF 1.6 internally, so the vector came out clean at 14 paths, no tracing or quality loss.
The one real tension

Your wordmark is very wide. Martian Mono is also very wide. Set at similar sizes they compete — two loud wide voices in one composition.

Fix: never put the wordmark next to a Martian headline at comparable scale. In the site header the wordmark sits small (~120px wide) and no display type appears in the same band. On the hero, either the wordmark is huge and there's no headline, or there's a headline and the wordmark stays in the nav.

This isn't a reason to change either one. It's a layout rule — and having a rule for it is why it won't become a problem.

03

Motif system — the logo's DNA

This is the part that makes a logo into an identity. Three details inside the wordmark become reusable system elements, so every page feels like it came from the same place as the mark — instead of the mark sitting on top of an unrelated layout.

M-A · The chamfer
12px cut · TL + BR

This replaces my radius: 0 rule. Square corners were the right instinct for the wrong reason — the goal was avoiding softness, and cut corners get there while actively echoing the mark.

Cut on top-left and bottom-right only, never all four. The asymmetry is the signature — four cuts reads as a generic sci-fi panel. --chamfer: 12px on containers, 7px on buttons and tags.
M-B · The tick rule

The stem hatching, pulled out and stretched into a divider. A ruler instead of a line — a measuring instrument doing the job of a piece of furniture.

Use for major section breaks only, roughly once per screen. Every hairline becoming a tick rule would be exhausting. Minor ticks in ink-3, majors every 5th in accent.
M-C · The inline
Static — featured
Hover me

The offset second contour from the letterforms, applied as a state. Amber inline = featured. White inline = hover or focus.

5px inset. This is a better focus indicator than a standard outline because it's already part of the brand's visual grammar — accessibility that looks intentional rather than bolted on.

/* the chamfer — TL + BR, never all four */
.chamfer{
  clip-path:polygon(
    var(--chamfer) 0, 100% 0,
    100% calc(100% - var(--chamfer)), calc(100% - var(--chamfer)) 100%,
    0 100%, 0 var(--chamfer)
  );
}

/* bordered chamfer — clip-path can't take a border,
   so nest: outer = border color, inner = fill */
.cham-box     { background:var(--c-rule); padding:1px; }
.cham-box > *  { background:var(--c-panel); }
05

Asset checklist

What to cut from the master artwork so the mark works everywhere it needs to. Roughly a half-day of vector work, and it's the difference between having a logo and having a brand.

Logo cuts
  • Master — full detail, SVG + AI, white-on-transparent
  • Inverted master — black-on-transparent for light backgrounds
  • Simplified — inline and tick marks removed, for 40–140px
  • Solid one-color — filled forms only, for vinyl / embroidery / etch
  • Glyph mark — the x alone, for favicon and avatars
  • Framed lockup — wordmark inside the chamfered keyline, as a stamp
  • Motto lockup — wordmark + manu et machina set at 10px below
Export set
  • favicon.svg + 32/180/512px PNG fallbacks
  • OG image 1200×630 — mark on black, chamfered frame
  • Email signature — 200px wide PNG @2x
  • Invoice / letterhead header block
  • Case sticker — one-color vinyl, road-case sized
  • Shirt back — IC-package repeat pattern using the chamfer motif
The road-case sticker matters more than it sounds. Your work sits in venues where other techs see it — that's the highest-intent audience you will ever have, and it costs $40.
