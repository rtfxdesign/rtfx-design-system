Overview

An industrial venue became a game-driven visual environment with LED walls, custom graphics, interactive racing, lighting, and live playback.

Challenge

One night, one room, one name on everything. A private event carries a different pressure than a public one — there is no second show, and the guest of honor is thirteen.

Response

I built the visual system around the party's own iconography: LED walls carrying custom graphics, an interactive racing game on the big screen, lighting keyed to the room's brick and steel, and live playback run from a single position.

Outcome

The room read as designed for exactly this event — and the documentation follows it from bare panels and road cases to a full crowd under the finished looks.
