Chamfered uppercase-mono button; use `fill` for the single primary CTA per viewport (accent discipline), outline for secondary, ghost for tertiary.

```jsx
<Button variant="fill">Start a project</Button>
<Button arrow>View build</Button>
<Button variant="ghost">Secondary</Button>
```

Props: `variant` outline|fill|ghost · `arrow` appends → · `href` renders an `<a>` · `disabled`.
